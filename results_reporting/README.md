# Reproducible Results Reporting

This folder contains the scripted reporting package for the completed
`RTDETR_AUTO_EVAL` suite run:

```text
RT_DETR/RTDETR_AUTO_EVAL/runs/camera_1_trim5/20260608_220235
```

The package does not contain hand-drawn or AI-generated plots. Every table and
figure in `outputs/` is generated by `generate_results.py` from the suite CSV
and JSON artifacts.

## Regenerate outputs

From the repository root:

```powershell
python .\results_reporting\generate_results.py
```

Optional arguments:

```powershell
python .\results_reporting\generate_results.py `
  --run-dir .\RT_DETR\RTDETR_AUTO_EVAL\runs\camera_1_trim5\20260608_220235 `
  --out-dir .\results_reporting\outputs `
  --top-n 10
```

The script overwrites only files inside the chosen output directory.

To copy only the comparison configs without regenerating plots and tables:

```powershell
python .\results_reporting\copy_report_configs.py
```

To copy only the three rendered inference videos:

```powershell
python .\results_reporting\copy_report_videos.py
```

## Metric definitions

- `mAP`: mean average precision from the suite evaluator at IoU threshold `0.5`.
- `AP`: class-specific average precision.
- `Precision` and `Recall`: final class precision/recall from the evaluator's
  confidence-sorted predictions.
- `Mean IoU` / `Median IoU`: matched-box IoU statistics for true positive
  detections.
- `IoU >= 0.75`: fraction of matched boxes with IoU at least `0.75`.
- `Matched Boxes`: number of detections matched to ground truth at IoU `0.5`.

## Central result

The report package is centered on the comparison between the manual Trim 5
configuration and the Auto-Tuned configuration. The expected headline
metrics from `summary.csv` are:

- Manual mAP: `0.5851`
- Tuned mAP: `0.7673`
- Cyclist AP: `0.4545 -> 0.8182`
- Cyclist recall: `0.4457 -> 0.8035`

The detector checkpoint is unchanged. The suite evaluates inference YAML and
tracking/post-processing parameter tuning, not retraining.
